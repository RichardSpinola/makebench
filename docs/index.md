# Makebench

Makebench is a visual workshop for small Linux desktop apps. You design windows,
program them with blocks or Python, test them in the editor and export a package that
runs without Makebench.

![The Design area](images/design.png)

## Start here

- **[User guide](user-guide.md)** — the workspace, one area at a time, from the Map to
  exporting. In Portuguese: **[Guia do usuário](user-guide.pt-BR.md)**.
- **[Writing plugins](plugins.md)** — add commands, templates, pieces and snippets, and
  how permissions and the catalog work.
- **[Compatibility](compatibility.md)** — what stays stable between releases.
- **[Building and packaging](building.md)** and **[Architecture](architecture.md)** — for
  people who want to look inside.
